# DecisionForge AI

## Project Overview

DecisionForge AI is a Java-based application that helps users make informed decisions by combining predefined rules and automated recommendations.

In this program, we evaluate two scenarios: CoursePath, which determines course registration eligibility, and LaptopWise, which recommends laptops based on user preferences and requirements.

## Technologies and Requirements

- Java (JDK 21 or later)
- IntelliJ IDEA
- Git and GitHub

## Execution

1. Download the project repository.
2. Open the project in your Java IDE.
3. Ensure all Java files are located in the `src` folder.
4. Open `Main.java`.
5. Run the Main class to launch DecisionForge AI.
6. Select CoursePath or LaptopWise from the main menu.

## Scenarios

### CoursePath (Scenario B)

CoursePath is designed to help students determine whether they are ready to register for a course based on their prerequisite completion, seat availability, registration holds and registration deadline requirements. It uses Boolean logic to determine eligibility, as well as a decision tree and knowledge graph to represent the registration process. To provide a decision support system, we used Boolean logic and conditional statements to create automated recommendations for the user.

### LaptopWise (Scenario C)

LaptopWise is designed to help students choose a laptop based on their preferences and requirements. The program asks users to enter their maximum budget, minimum RAM, preferred laptop weight and warranty requirements. It then uses Boolean logic and conditional statements to determine which laptops meet all four conditions. The program recommends laptops that qualify and explains why others do not meet the requirements. It also uses a knowledge graph to show the relationships between laptops and their specifications, helping users understand how the recommendations are made.

## Project Structure

`Main.java → DecisionForgeApp.java → Selected Scenario`

1. The Main class launches the application.
2. DecisionForgeApp displays the main menu.
3. The user selects CoursePath or LaptopWise.
4. The selected scenario evaluates the user's input and generates a recommendation.
5. The user can return to the menu or exit the application.

## Features

- Interactive menu
- Boolean and propositional logic
- Decision trees
- Knowledge graphs
- Rule-based recommendations
- Input validation
